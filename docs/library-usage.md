# Using numbl as a library

The library documentation is maintained as a user-facing page: [src/docs/library.md](../src/docs/library.md) (published at [numbl.org/docs/library](https://numbl.org/docs/library)). It covers `executeCode`, `ExecSession`, hosts (`createHost`, the platform capabilities a session runs with), the `numbl/node` adapters and `initNodePlatform`. For how hosts work inside numbl and how to add a capability, see [developer_reference/architecture.md](developer_reference/architecture.md#host-capabilities). For running numbl in a third-party web page, see [developer_reference/browser-embedding.md](developer_reference/browser-embedding.md).
