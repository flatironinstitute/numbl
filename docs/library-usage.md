# Using numbl as a library

The library documentation is maintained as a user-facing page: [src/docs/library.md](../src/docs/library.md) (published at [numbl.org/docs/library](https://numbl.org/docs/library)). It covers `executeCode`, `ExecSession`, the `numbl/node` adapters and `initNodePlatform`. For running numbl in a third-party web page, see [developer_reference/browser-embedding.md](developer_reference/browser-embedding.md).
