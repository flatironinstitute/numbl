# MATLAB Compatibility

The user-facing compatibility documentation lives in `src/docs/` and is published at [numbl.org/docs](https://numbl.org/docs):

- [src/docs/language.md](../src/docs/language.md): supported language features and data types.
- [src/docs/builtins.md](../src/docs/builtins.md): built-in functions by category (`numbl list-builtins` prints the full list).
- [src/docs/plotting.md](../src/docs/plotting.md): plot types and figure commands.
- [src/docs/differences.md](../src/docs/differences.md): unsupported features and behavioral differences, including the `eig` dispatch and the sparse direct solvers.

Update those pages when a change alters what numbl supports.
